## Why this is small

We already scan pasted text for hidden Unicode (`src/lib/unicode/hidden.ts`,
surfaced through the `hidden-unicode` signal). This brief mostly *accepts a
file* where today we accept only a paste, and adds the document-level carriers
that a `.md` file has and a paste does not.

## What to add

| Carrier | Notes |
|---|---|
| YAML frontmatter AI keys | `generator`, `ai_generated`, `model`, `prompt`, `assistant`, `tool` and similar, inside the leading `---` fence. |
| JSON-LD blocks | `<script type="application/ld+json">` — carries `creator` / `provider` / generator identifiers. |
| HTML comments | `<!-- generated by … -->`, editor and export breadcrumbs. |
| HTML `<meta>` tags | `generator`, `author` — Markdown routinely carries raw HTML. |
| Hidden Unicode | Existing scanner, unchanged, across the whole document. |

## The formatting trap

Markdown files are hand-edited source. If we parse the YAML and re-serialise
it, we will silently reorder keys, restyle quotes, normalise indentation and
rewrite line endings — and hand the user back a file that produces a noisy diff
in their repo. For a tool whose promise is "we changed only what we said we
changed", that is a real defect even though nothing is lost.

**Required:** surgical, line-level removal. Delete the offending lines and
nothing else. Everything you did not deliberately remove must be byte-identical,
including CRLF vs LF, trailing whitespace, and the absence or presence of a
final newline.

This means you need a frontmatter *locator*, not a YAML parser. You need to know
which byte range a key occupies. You do not need YAML semantics, and you must
not add a YAML dependency (**no runtime deps in `src/lib/`** — non-negotiable).

Handle, at minimum: nested keys under an `ai:` parent, multi-line block scalars
(`|` and `>`), and a key whose value spans lines as a list. When you cannot
confidently determine a key's extent, **do not guess** — report it as detected,
mark it not removable, and let the honesty rule do its job.

## Scope boundary

Markdown only — `.md`, `.markdown`, `.txt`. **HTML, DOCX and ODT are explicitly
out of scope** for this brief. They were on the competitor's list, but they are
agent-workflow formats that do not match this site's audience, and DOCX/ODT are
zip containers that would drag in a decompressor.

## Rules you must not break

1. No runtime dependencies.
2. Byte-exact preservation of everything not removed (see above).
3. Cleaning routes through `clean.ts`; the removal report comes from a second
   independent scan diffed against the first.
4. `src/lib/signals.ts` governs every claim.
5. **`claude-watermark` stays `remove: false`.** A Markdown file can absolutely
   carry a statistical text watermark, and finding frontmatter does not touch
   it. Do not let the presence of a file make the claim stronger than it is for
   a paste. See `src/lib/signals.ts:176`.
